# OpenHarmony 7.0 源码位置

本目录只保留源码存放约定，不包含 OpenHarmony 源码。

- `.submodules/openharmony` 是官方 manifest 仓库的固定版本入口。
- `openharmony-source.lock.json` 和 `manifests/openharmony-7.0.xml` 记录本期 `OpenHarmony-v7.0-Release` 源码基线。
- 完整源码保存在项目外的区分大小写文件系统；已有源码只读校验通过后可以复用。
- 操作步骤和当前完成范围见 [OpenHarmony 源码说明](../../docs/openharmony.md)。
