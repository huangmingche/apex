# Apex

[简体中文](README.md) | **English**

Apex is an open-source AI Operating System based on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), with its operating system framework and platform capabilities provided by [OpenHarmony](https://gitcode.com/openharmony/manifest). It adopts the design principle "Everything is a Plugin".
